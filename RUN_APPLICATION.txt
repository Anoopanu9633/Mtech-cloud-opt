  🚀 EXACT COMMANDS TO RUN YOUR APPLICATION
═══════════════════════════════════════════════════════════════

📋 OPEN POWERSHELL AND RUN THESE COMMANDS IN ORDER:


STEP 1: Add Azure CLI to PATH
─────────────────────────────────────────────────────────────
$env:Path += ";C:\Program Files\Microsoft SDKs\Azure\CLI2\wbin"


STEP 2: Login to Azure
─────────────────────────────────────────────────────────────
az login --service-principal -u $env:AZURE_CLIENT_ID -p $env:AZURE_CLIENT_SECRET --tenant $env:AZURE_TENANT_ID


STEP 3: Set Subscription
─────────────────────────────────────────────────────────────
az account set --subscription $env:AZURE_SUBSCRIPTION_ID


STEP 4: ⭐ START THE APPLICATION ⭐
─────────────────────────────────────────────────────────────
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

   ✨ Server will start on http://localhost:8000
   ✨ Keep this terminal running

❌ TROUBLESHOOTING:
─────────────────────────────────────────────────────────────

If port 8000 is already in use:
   netstat -ano | findstr :8000
   taskkill /PID <PID> /F

If Azure authentication fails:
   • Check .env file has correct credentials
   • Verify Azure service principal exists
   • Check role assignments: Monitoring Reader, Cost Management Reader

If Python is not found:
   • Verify Python 3.14+ is installed
   • Add Python to PATH
